# Перепроведение туров

Техническая заготовка внешней обработки для перепроведения документов `Тур` после изменения модуля проведения.

## Когда нужна

- В базе уже есть проведенные документы `Тур`.
- Нужно пересоздать движения регистра накопления `Игры`.
- Нужно заполнить измерение `Страна` в старых движениях.
- Нужно пересчитать реквизит документа `СыграноИгр`.

## Как использовать

1. Создать внешнюю обработку в конфигураторе.
2. Добавить управляемую форму.
3. Добавить реквизиты формы:
   - `Сезон`, тип `СправочникСсылка.Сезоны`;
   - `ДатаНачала`, тип `Дата`;
   - `ДатаОкончания`, тип `Дата`;
   - `ТолькоПроведенные`, тип `Булево`.
4. Добавить команду формы `Выполнить`.
5. В модуль формы вставить код из `ФормаОбработки_Module.bsl`.
6. Открыть обработку в нужной базе и выполнить перепроведение.

По умолчанию обработка должна работать по текущему сезону и только по уже проведенным документам.
